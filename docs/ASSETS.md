# Where images live in Inkora

Two categories, two homes. Pick by **who owns the image** and **whether it ships with the app**.

## 1. Bundled assets (in the repo, shipped with each app)
Brand/UI chrome that's identical for every user.

| Location | App | Use for |
|---|---|---|
| `apps/mobile/assets/` | Mobile | App icon, splash, adaptive icon, fonts |
| `apps/mobile/assets/images/` | Mobile | In-app logos, illustrations, empty-state art (`require(...)`) |
| `apps/web/public/` | Web | Favicon, OG/social images, marketing visuals (served at `/...`) |
| `apps/web/public/images/` | Web | Static web UI/marketing images |

## 2. Hosted images (Supabase Storage, fetched by URL)
Content imagery — curated by you OR generated by users.

| Bucket | Visibility | Source | Staged in repo? |
|---|---|---|---|
| **`styles`** | public | **Tattoo-style snapshots** (onboarding) | ✅ `supabase/storage/styles/` → upload |
| `ideas` | public | Inspiration feed images | user uploads at runtime (curated seed optional) |
| `avatars` | public | Profile pictures | user uploads at runtime |
| `portfolio` | public | Artist portfolio images | artist uploads at runtime |
| `chat-attachments` | private | Message images | user uploads at runtime |
| `journey` | private | Personal tattoo-journey photos | user uploads at runtime |
| `ai-previews` | private | Saved mobile try-on composites; model-generated previews remain unimplemented | user uploads at runtime |
| `saved-designs` | private | Saved Create-Idea concepts | user uploads at runtime |

### 👉 Style images (the ones you asked about)
Drop the 10 files (`<slug>.jpg`) in **`supabase/storage/styles/`** and run the uploader:
```bash
SUPABASE_URL="https://your-project.supabase.co" \
SUPABASE_SERVICE_ROLE_KEY="your-service-role-key" \
node supabase/storage/upload.mjs styles
```
See `supabase/storage/styles/README.md` for the exact filenames.

## Decision rule
- Same for everyone + part of the app's look → **bundled** (`assets/` or `public/`).
- Tattoo/content imagery, or anything users create → **Supabase Storage bucket**.
