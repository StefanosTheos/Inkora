# @inkora/design-tokens

The one shared visual source. A brand/spacing change happens here once and propagates to **both** apps:

- **web** imports `./tailwind-preset` into `tailwind.config`
- **mobile** imports the same preset into its NativeWind config

This is how the apps look like one product without sharing components.
