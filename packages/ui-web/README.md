# @inkora/ui-web — 🖥️ WEB ONLY

**PLATFORM: Web (Next.js) only.** Do NOT import from `apps/mobile`. Built on shadcn/ui + Tailwind, themed from `@inkora/design-tokens`.

Mirrors `@inkora/ui-native` in *intent* (same names/props where sensible), separate implementation.

Components (placeholders): `Button`, `Card`, `Sheet`, `Dialog`, `Input`, `Badge`, `Skeleton`, `EmptyState`, `DataTable` (dashboards).
